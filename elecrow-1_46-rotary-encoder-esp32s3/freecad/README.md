# FreeCAD add-on

`RotaryHid/` is a small FreeCAD add-on that lets the Rotary Macro Pad's ring
rotate FreeCAD's 3D view about the world X, Y or Z axis, 5° per click.

To install it, open `RotaryHid_Install.FCMacro` in FreeCAD (**File → Open**)
and press **Run**. It copies `RotaryHid/` into FreeCAD's `Mod` folder and
activates it straight away.

Details: [docs/linux-setup.md, part 3](../docs/linux-setup.md#part-3--freecad-add-on)
